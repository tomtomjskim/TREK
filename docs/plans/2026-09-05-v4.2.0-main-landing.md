**Goal:** 공식 TREK v4.2.0과 포크 기능을 충돌 없이 `main`에 흡수하고, 선택 addon을 일관되게 탈부착 가능하게 만든 뒤 OpenFreeMap을 유지한 ARM64 운영 이미지를 안전하게 배포한다.

**Architecture:** 공식 tag commit을 merge parent로 보존하고 포크 변경은 domain module/common addon gate/instance-only config로 분류한다. Vacay와 Packing은 동일 addon capability를 REST·MCP·desktop·mobile·admin UI에 적용하고, DB migration은 runtime toggle과 분리한다. v4.2 schema 경계를 되돌릴 때는 이전 image와 logical-point full-state backup을 함께 사용한다.

**Tech Stack:** TypeScript, React, Zustand, NestJS, Vitest, Playwright, SQLite/better-sqlite3, Docker Compose, native ARM64 Docker build
